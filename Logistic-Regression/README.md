# Logistic Regression

This folder contains **Machine Learning projects focused on Logistic Regression and classification problems**, implemented using Python and Scikit-learn.

The projects demonstrate how Logistic Regression can be applied to real-world datasets for binary classification and prediction.

---

### Heart Disease Risk Prediction

This project uses **Logistic Regression** to predict the risk of heart disease based on health-related, demographic, and lifestyle factors.

The project includes data exploration, preprocessing, feature selection, categorical data encoding, model training, prediction, and classification model evaluation.

**Key Concepts:**
- Logistic Regression
- Binary Classification
- Data Cleaning
- Exploratory Data Analysis
- Feature Selection
- Categorical Encoding
- Train-Test Split
- Model Prediction
- Classification Report
- Accuracy
- Precision
- Recall
- F1-Score
