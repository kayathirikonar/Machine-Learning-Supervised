# Linear Regression

This folder contains a collection of **Machine Learning projects focused on Linear Regression and related concepts**, implemented using Python and Scikit-learn.

The projects cover regression modeling, model evaluation, regularization, feature engineering, and prediction using different datasets.

---

### 1. Evaluation Techniques

This project focuses on understanding and evaluating the performance of a **classification model** using Logistic Regression and the Employee Attrition dataset.

**Key Concepts:**
- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix
- Classification Report
- Model Evaluation

---

### 2. L1-L2 Regularization

This project compares **Linear Regression, Lasso Regression, and Ridge Regression** for house price prediction. It demonstrates how regularization techniques can help control model complexity and reduce overfitting.

**Key Concepts:**
- Linear Regression
- Lasso Regression
- Ridge Regression
- L1 Regularization
- L2 Regularization
- Overfitting
- Mean Squared Error (MSE)

---

### 3. Social Media Engagement Forecasting

This project uses **Simple Linear Regression** to analyze the relationship between social media shares and viral content performance.

**Key Concepts:**
- Simple Linear Regression
- Correlation Analysis
- Regression Line
- Prediction
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)

---

### 4. Stroke Feature Engineering

This project focuses on **feature engineering and data preprocessing** using a healthcare stroke dataset. It demonstrates techniques used to prepare data for machine learning.

**Key Concepts:**
- Data Cleaning
- Handling Missing Values
- Categorical Encoding
- Feature Scaling
- StandardScaler
- Feature Engineering
- Data Preprocessing

---

### 5. Viral Content Forecasting

This project uses **Multiple Linear Regression** to predict viral content performance using multiple input features.

**Key Concepts:**
- Multiple Linear Regression
- Feature Selection
- Correlation Analysis
- Model Prediction
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Regression Analysis
