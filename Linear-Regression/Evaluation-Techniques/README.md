# Understanding Evaluation Metrics for Classification Models

## Project Overview

This project focuses on understanding and evaluating the performance of a **Logistic Regression** classification model using various **classification evaluation metrics**. The objective is to learn how different metrics measure model performance and determine whether a classification model is reliable for predicting employee attrition.

## Evaluation Metrics

The project demonstrates how to evaluate a classification model using the following metrics:

* **Accuracy:** Measures the overall percentage of correct predictions.
* **Precision:** Indicates how many predicted positive cases are actually positive.
* **Recall (Sensitivity):** Measures the model's ability to correctly identify positive cases.
* **F1-Score:** Provides a balanced measure of Precision and Recall.
* **Confusion Matrix:** Visualizes True Positives, True Negatives, False Positives, and False Negatives.
* **Classification Report:** Summarizes Precision, Recall, F1-Score, and Support for each class.

---

## Results

The project demonstrates how different evaluation metrics provide a comprehensive understanding of a classification model's performance. Rather than relying solely on accuracy, metrics such as Precision, Recall, F1-Score, and the Confusion Matrix offer deeper insights into the model's predictive capabilities, making them essential for evaluating binary classification problems like employee attrition prediction.
