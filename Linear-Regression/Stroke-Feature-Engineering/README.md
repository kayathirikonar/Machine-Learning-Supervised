# VitalFeat: Advanced Feature Engineering & Selection for Stroke Prediction

## Project Overview

This project focuses on **Feature Engineering and Data Preprocessing** for a healthcare stroke prediction dataset. The objective is to prepare the dataset for machine learning by cleaning, transforming, encoding, and scaling features to improve model performance and data quality.

---

## Dataset

The dataset contains patient health information, including:

- Gender
- Age
- Hypertension
- Heart Disease
- Ever Married
- Work Type
- Residence Type
- Average Glucose Level
- BMI
- Smoking Status
- Stroke (Target Variable)

### Dataset Size

- **5,110 Records**
- **11 Input Features**
- **1 Target Variable**

## Results

The project demonstrates how feature engineering and preprocessing techniques improve data quality and prepare healthcare data for machine learning models. Applying feature scaling ensures that numerical features are standardized, making them suitable for algorithms that are sensitive to feature magnitude and improving overall model readiness.
