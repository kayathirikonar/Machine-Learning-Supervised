# Viral Content Prediction using Multiple Linear Regression

## Project Overview

This project predicts the **Viral Score** of social media content using **Multiple Linear Regression**. The model analyzes how **Social Media Shares** and **Content Length** influence content virality, helping understand the factors that contribute to higher engagement.

---

## Dataset

The dataset contains the following variables:

- **Social Media Shares:** Number of times the content was shared.
- **Content Length (words):** Total number of words in the content.
- **Viral Score:** Target variable representing the virality of the content.

### Dataset Size

- **100 Records**
- **2 Input Features**
- **1 Target Variable**

## Evaluation Metrics

The model performance is evaluated using:

- **Mean Absolute Error (MAE):** Measures the average absolute difference between actual and predicted viral scores.
- **Mean Squared Error (MSE):** Measures the average squared difference between actual and predicted values.

These metrics help assess the prediction accuracy and overall performance of the regression model.

---

## Results

The Multiple Linear Regression model demonstrates how **Social Media Shares** and **Content Length** jointly influence the **Viral Score**. The evaluation metrics provide insights into the model's prediction accuracy, making it useful for understanding and forecasting content virality.
