# Social Media Engagement Forecasting using Linear Regression

## Project Overview

This project analyzes the relationship between **Social Media Shares** and **Viral Score** using **Simple Linear Regression**. The objective is to understand how social media engagement influences content virality and to build a predictive model for estimating the viral score based on the number of shares.

---

## Dataset

The dataset contains two variables:

- **Social Media Shares:** Number of times the content was shared.
- **Viral Score:** A score representing the virality of the content.

### Dataset Size

- **100 Records**
- **1 Input Feature**
- **1 Target Variable**

## Evaluation Metrics

The model performance is evaluated using:

- **Mean Absolute Error (MAE):** Measures the average absolute difference between actual and predicted viral scores.
- **Mean Squared Error (MSE):** Measures the average squared prediction error.
- **Root Mean Squared Error (RMSE):** Indicates the average prediction error in the same unit as the target variable.

---

## Results

The Linear Regression model demonstrates a positive relationship between **Social Media Shares** and **Viral Score**, indicating that higher social media engagement is associated with increased content virality. The evaluation metrics provide insights into the prediction accuracy and overall model performance.
